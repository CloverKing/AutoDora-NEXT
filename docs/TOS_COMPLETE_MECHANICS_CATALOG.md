## 二、特殊符石状态与障碍类（13 年全谱系 `HazardBits`）

> 注意区分四大本质行为：**① 不可触碰（碰即停/即死）**、**② 不可消除（只能绕或消邻格）**、**③ 必须消除（不消扣血/零伤/扩散/变冰封）**、**④ 尽量避消（消了扣攻/扣血）**。

| 状态符石 | 游戏内真实规则 | C++20 求解器策略 | 当前状态 |
|---|---|---|---|
| **强化符石（`+`）** | 破强化盾、强化拼图盾、五属强化盾、增伤 | `Variant::ENCHANTED` + 强引导启发式 | **已实装** |
| **种族符石（人/神/魔/兽/龙/妖/机械）** | 右上角带黑白种族徽章；破种族符石盾、触发种族加攻 | CV 圆环采样屏蔽右上角徽章区 + `CellState.raceMask` 种族盾约束 | **待新增（高优）** |
| **角色符石（角色珠）** | 从角色头像垂直下拉首格（**拉下本身不计入转珠步数**）；不受多数结界地形影响；需配合角色珠盾/角色珠通行与停放地形 | 已支持垂直下拉；补齐「**不计步数**」+「**必须经过/停放在指定地形格**」 | **部分→强化** |
| **流光符石（时光牌 / 辰曦塔）** | 消除储 FP 能量；满能后拖入角色头像入珠触发即时/回合/连动破盾效果 | 优先消除加权（入珠由玩家主动触发） | **待新增（权重）** |
| **风化符石（普通/先攻/扣血/扩散）** | **一经触碰即时停止转珠**并扣血（撞击后消失） | 路径硬避障（不可踏入，可通过消除化解） | **已实装** |
| **电击符石** | **一经触碰即时停止转珠**（撞不掉）且**未消完当回合全队零伤** | 路径硬避障 + **必须全部消除**硬约束 | **已实装** |
| **黏腐符石 / 黏腐之地** | **一经触碰即时停止转珠**（部分附带扣血/限步） | 路径硬避障（不可踏入） | **待新增** |
| **连环光牢 / 射击光牢** | 敌方射击指定行/列/格附加光牢，**一经触碰即时停止转珠** | 路径硬避障（按行列快速标记） | **待新增** |
| **炼狱之火（场景/敌技）** | **一经触碰召唤师即时死亡**（无视一切减伤与意志） | **绝对禁入硬障碍**（与普通燃烧严格区分） | **待新增** |
| **燃烧符石 / 灼热地型（1~3重）** | 每次经过扣除 10%~20%+ 生命力（不中断转珠） | 软/硬避开路径惩罚（可调权重或完全禁入） | **已实装** |
| **冻结符石（封前）** | 当回合**可手动消除**；若未消除则下回合转为 3 回合不可消的「冰封」 | **高优必消约束**（与风化/电击不同，可正常经过与消除） | **待新增** |
| **冰封符石（永久/3回合）** | 完全结块，**不可消除、不可转化、不可引爆**（视技能部分不可移动） | **不可消除掩码**（类似碎裂/石化不可直消） | **待新增** |
| **石化符石（1重 / 多重）** | 本身不可消除；必须**消除上下左右 4 侧相邻符石**逐层敲碎（1C 解 1 层） | 不可直消 + **新增「邻格消除解层」奖励/硬约束** | **部分→强化** |
| **泡沫符石（泡沫之护）** | 不可消除/转化/引爆；必须**消除四侧相邻符石**解除，否则全队攻击归 0 或失去护盾 | 不可直消 + **全部泡沫邻格必消**硬约束 | **待新增** |
| **碎裂符石** | 不可消除/不可炸版，但转珠时**可以正常穿越** | `SHATTERED`（可穿越、不可消） | **已实装** |
| **爆弹 / 点燃 / 熔焰焚爆符石** | 当回合未消除则引爆造成巨额伤害/自爆 | **必须全部消除**硬约束 | **已实装** |
| **化血符石** | 未消除则敌人按我方伤害等额回血 | **必须全部消除**硬约束 | **已实装** |
| **腐蚀符石** | 未消除会向周围扩散并每回合扣血 | **必须全部消除**硬约束 | **待新增** |
| **锁定符石（A型：未消扣血/引爆/回血）** | 未消除触发扣血/引爆/帮敌回血 | **必须消除**硬约束 | **待新增** |
| **锁定符石（B型：消除扣攻）** | 每消除 1 颗全队攻击力大幅下降 | **尽量避消 / 禁消**惩罚 | **待新增** |
| **弱化符石** | 每消除 1 颗全队攻击力降低指定百分比 | **尽量避消**惩罚权重 | **待新增** |
| **枯藤符石（场景特性）** | 未消除则当回合无法回复生命 | 可选「必须消除」软/硬约束 | **待新增** |
| **睡眠符石** | 碰触惊醒敌方或需首消特定符石唤醒 | 可选「避碰 / 必消」标记 | **待新增** |
| **暴风符石 / 暴风席卷** | 区域内不可消除、不可引爆，且**碰触即停** | `STORM`（禁入 + 禁消） | **已实装** |
